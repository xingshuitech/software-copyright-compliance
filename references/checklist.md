# 送审前检查清单

按顺序执行，任何一步失败都先修复再继续。

## 零、合规边界

- [ ] 已告知申请人 2026-03-15 新版申请表的签章承诺内容。
- [ ] 已确认材料基于真实开发事实，无虚构日期、命令、测试结果或人员。
- [ ] 助手起草的材料，申请人已逐字核实并按真实情况修改确认。
- [ ] 签章页由申请人本人手抄，未代抄、未预填、未改动格式。
- [ ] 经办人签名和身份证号码按系统要求填写。
- [ ] 主要功能字数在 500–1300 字之间。
- [ ] 已知悉失信惩戒与个人征信后果。

## 一、口径

- [ ] 已确认软件全称和登记版本。
- [ ] 已确认著作权人署名方式；记录人员与著作权人没有混写。
- [ ] 已确认登记范围，第三方依赖和构建产物已排除。
- [ ] 已确认开发完成日期，不使用材料编制日期代替。
- [ ] 申请表中的软件名、版本、语言、源程序量已与材料对齐。
- [ ] 鉴别材料页眉版本号与申请表一致，有无 `V` 也一致。
- [ ] 已确定采用一般交存还是例外交存；交存方式符合《办法》第十、十二条。

## 二、版本库

- [ ] 已检查工作区是否为 Git 仓库。
- [ ] 没有伪造提交标识。
- [ ] 不以第三方底座的提交充当本软件提交。
- [ ] 非Git项目改用开发过程记录，依据日志和文件时间编制。

## 三、文档生成

- [ ] 从零生成 DOCX，没有复用旧模板字节。
- [ ] 部件数恰好 9 个，无 `app.xml`、`customXml`、`word/media`。
- [ ] 页眉为「软件全称 + 空格 + 版本」，末尾有空格。
- [ ] 右上角 `PAGE` 域存在，页码从 1 开始。
- [ ] 普通文档每页 30–34 行；源程序材料每页 50–56 行。
- [ ] 无颜色、底纹、高亮、背景、白色填充、图片、绘图对象。
- [ ] 暗色预览下没有文字白块。
- [ ] 文档属性无 `cp:revision`，creator 和 lastModifiedBy 符合口径。

生成命令：

```bash
python scripts/build_minimal_docx.py content.txt output.docx "软件名 V1.0" \
  --title "用户手册" --creator "记录人员" \
  --min-lines 30 --max-lines 34

python scripts/build_minimal_docx.py source.txt code.docx "软件名 V1.0" \
  --title "源程序" --source --min-lines 50 --max-lines 56
```

## 四、源程序鉴别材料

核验命令：

```bash
python scripts/verify_source.py --docx "源程序鉴别材料.docx" --source-dir "源码目录"
```

- [ ] 每个文件按原顺序全文收录，无删改。
- [ ] 文件前后有 `===== 路径 =====` 和 `===== 路径 END =====`。
- [ ] 超长行已按可视宽度软换行，未增删字符。
- [ ] 已运行 `scripts/verify_source.py`，逐文件核验结果为 `IDENTICAL`。
- [ ] 末页是程序结束页。
- [ ] 功能常量、内部版本号、调试开关、引用内部文档的注释均保留。
- [ ] 只修复了真正的编辑残留，并且源码与鉴别材料同步修改、测试通过。

## 五、写作

- [ ] 没有目录页、术语表、功能对照表、一致性核对表。
- [ ] 没有把内部笔记文件列成交付成果。
- [ ] 没有「随着信息技术发展」「性能优越」「应用前景广阔」等套话。
- [ ] 写了真实文件名、命令、报错、参数、数值和边界。
- [ ] 没有「原创算法」「不可破解」「国内领先」等无法验证的结论。
- [ ] 用户手册、算法说明、开发记录三份材料观察角度不同，不重复堆砌。

## 六、PDF

- [ ] 只收 PDF 的栏位已上传 PDF，不是 DOCX。
- [ ] PDF 页数与 DOCX 一致，无空白页。
- [ ] 已执行元数据清理。

清理命令：

```bash
python -m pip install pypdf
python scripts/clean_pdf_metadata.py input.pdf output.pdf \
  --title "软件名 文档名" --author "记录人员" --subject "文档类别"
```

- [ ] `/Producer` 为空。
- [ ] `/Creator` 为空。
- [ ] XMP 元数据块不存在。
- [ ] 无 `pdf:Producer`、`xmp:CreatorTool`、`LibreOffice`、`Writer` 残留。

## 七、全量终检

对所有 DOCX 和 PDF 执行：

```bash
python scripts/scan_aigc.py "材料目录" \
  --header "软件名 V1.0" --min-lines 30
```

源程序鉴别材料单独按 50 行复扫：

```bash
python scripts/scan_aigc.py "源程序鉴别材料.docx" \
  --header "软件名 V1.0" --min-lines 50
```

判定：

- `OK`：可提交。
- `WARN`：确认警告是否可接受；pypdf 未安装属于环境问题，装好后复扫。
- `FAIL`：逐条修复后重新生成、重新清理、重新扫描。

注意：`generator` 出现在真实源码注释里属于正常内容，不要为了扫描结果去改功能代码。
